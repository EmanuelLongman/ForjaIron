# FORJA Iron Club

Site de academia feito em React (Vite). Só front end, com dados de exemplo.

## Recursos
- Hero com haltere animado
- Serviços, equipamentos (halteres, anilhas, kettlebells e barra em SVG)
- Grade semanal de aulas com reserva e cancelamento (salva no aparelho)
- Planos com preço mensal, trimestral e anual
- Equipe, calculadora de IMC e formulário de aula experimental
- Modo claro e escuro automático

## Rodar no computador
```bash
npm install
npm run dev
```

## Publicar no GitHub Pages
1. Em Settings > Pages, escolha **Source: GitHub Actions**.
2. Faça push na branch `main`. O deploy roda sozinho.
